# OFF COURSE — The GeoFS Magazine

Static GitHub Pages site for OFF COURSE.

- `index.html` — homepage explaining OFF COURSE and the latest release.
- `library.html` — issue library with embedded Heyzine readers.

## Add a new issue
1. Put the cover in `assets/`.
2. Add/copy an entry in the `issues` array in `app.js`.
3. Set `available: true` and add the issue number, date, title, description, page count, cover path, and Heyzine flipbook ID.
